# DuoSync companion

An original mint folded-page creature: two soft panels, curious eyes, small feet. It evokes the helpful presence of a classic desktop companion without copying Clippy. The shape echoes the two surfaces of DuoSync and remains recognizable in the floating button.

Production image: `DuoSync/Assets.xcassets/CompanionPet.imageset/companion.png`, 1254 × 1254 PNG with alpha. Generated with the built-in image-generation tool on September 26, 2026. Original output copied intact; no raster editing or background replacement applied.

`CompanionPet.swift` uses the same image for three native motion states: subtle idle bob/tilt, capture pulse, and a single ready lift. Reduced Motion and inactive-scene behavior stop decorative animation. The pet never implies live model activity when only local capture is running. Tap/drag handling and VoiceOver live in the parent control.

Open `design/pet-preview.html` for a lightweight browser motion preview. This previews asset motion only, not the native app or Duo layout. Native testing remains on the board.
